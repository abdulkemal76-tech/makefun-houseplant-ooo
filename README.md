An entry for the make.fun bounty [The Houseplant Out-of-Office](https://make.fun/bounty/u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047): a program that writes the funniest out-of-office auto-reply a houseplant would send, 120 characters or fewer.

## Run

```sh
python3 -P -s main.py
```

It writes the auto-reply to `/output/entry.txt`.

## The reply

> Out of office. The cactus survived 214 days without water and is returning the favour. Your emails go unwatered too.
